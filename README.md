# FRC Prototype Simulator

A design tool for FRC robots: bring a robot as rough blocks or as CAD, mark what moves and what
spins, and see whether it picks the game piece up, how fast it cycles, what it draws from the
battery, and whether it tips.

Nothing is built yet. [PLAN.md](PLAN.md) is the design and the order of work. `spikes/` holds the
measurements the plan rests on.
